# 📚 BookFly Libre

Lector digital moderno desarrollado con HTML, TailwindCSS y JavaScript.

## ✨ Características

- Lectura de archivos:
  - EPUB
  - PDF
  - TXT
  - HTML

- Interfaz moderna
- Modo maximizado
- Biblioteca digital local
- Animaciones elegantes
- Barra de carga
- Sistema de eliminación de libros

## 🚀 Proyecto

Desarrollado y probado con GitHub Pages.
